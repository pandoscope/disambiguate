# Skill rules

These rules hold for skill files.

- `skill-register` [M] Write skill prose in concise complete sentences, where filler and narrative go and grammar stays.
- `audience` [M] Address only the agent running the skill, and move rationale meant for reviewers into code or records.
- `no-op` [M] Delete a sentence the model already obeys without it.
- `reason` [M] Give a reason only where it changes what the agent does.
- `positive` [M] Phrase an instruction positively, and keep a prohibition only as a guardrail paired with what to do instead.
- `skill-glossary` [M] Put the instruction in the skill and the explanation in the linked entry, never both.
